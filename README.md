# sonunsuu-coder portfolio

A responsive, dark developer portfolio made with plain HTML, CSS and JavaScript. No build tools required.

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a **public** repository named `sonunsuu-coder.github.io`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your site will be available at `https://sonunsuu-coder.github.io` after GitHub Pages finishes deploying.

## Personalize
- Edit your introduction and skills in `index.html`.
- Replace the sample GitHub project card with real projects when you have them.
- Add your preferred contact links in the contact section.

This starter intentionally avoids inventing a bio, work history, skill level, or project list.
